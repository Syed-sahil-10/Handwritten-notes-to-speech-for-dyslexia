# Handwritten-notes-to-speech-for-dyslexi

## 📌 Project Overview
This project aims to assist children with dyslexia by converting handwritten notes into readable text and speech using deep learning and text-to-speech technology.

## 🎯 Objectives
- Recognize handwritten text from uploaded images.
- Convert recognized text into speech.
- Make written learning materials more accessible.
- Explore text recognition quality using evaluation metrics.

## 🛠️ Technologies
- **Language:** Python
- **Deep Learning:** TrOCR, PyTorch, Hugging Face Transformers
- **Image Processing:** OpenCV, Pillow
- **Text-to-Speech:** gTTS
- **Interface:** Gradio / Streamlit (depending on the implementation)

## ⚙️ Workflow
1. Upload an image containing handwritten notes.
2. Preprocess the image.
3. Recognize the handwriting using a deep-learning model.
4. Apply text correction if implemented.
5. Convert the recognized text into speech.
6. Evaluate recognition quality where supported.

## 📂 Project Files
- `DYSLEXIA_FINAL.ipynb` — Jupyter notebook containing the project implementation.

## 🚀 Getting Started
1. Clone or download this repository.
2. Install the dependencies required by the notebook.
3. Open the notebook in Google Colab or Jupyter Notebook.
4. Run the cells in order and provide a handwritten image when prompted.
